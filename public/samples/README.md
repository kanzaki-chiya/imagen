# Demo images

These four original sample images were created with the built-in image generation tool for this project. They are bundled locally; there are no external image URLs or runtime image API calls.

- `alpine.png`: A pristine turquoise alpine lake reflecting jagged snowy mountains, evergreen forest, morning mist and warm first light; cinematic 3:2 editorial landscape photograph.
- `coast.png`: A secluded Mediterranean cove with pale limestone cliffs, turquoise water, a sandy beach and dark pine trees; summer editorial travel photograph.
- `desert.png`: Sculptural terracotta sand dunes at sunrise, a graceful curving ridge, rust shadows, apricot light and distant mauve mountains; fine-art landscape photograph.
- `botanical.png`: A matte off-white ceramic vase with a sculptural dark green monstera leaf on travertine; sage-gray backdrop and soft directional light; editorial product photograph.

Common prompt constraints: one full-bleed 3:2 composition, natural detailed textures, no text, no branding, no borders, no interface and no people.
